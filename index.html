Personal projectv1.11.0Android · iPhone · Web

Smart Expense Tracker

Snap a receipt, the app does the rest.

Take a photo of a receipt and the app reads it for you (store, date, items and total), files it under the right category and turns it into spending dashboards. I designed, built and run it end to end on my own: a Flutter app, a serverless Azure backend, Terraform infrastructure and automated releases, all for about $0 a month.

Try the live demo Android APK iPhone IPA Project site

In the demo, tap “Try the demo account”: no sign-up needed. The IPA is unsigned; install it with Sideloadly and a free Apple ID.

Architecture & DevOps
  • Event-driven, serverless pipeline: the photo goes straight to Blob Storage, then Event Grid and a queue-triggered Azure Function send it to AI Document Intelligence. The expense is ready in about 15 seconds, with retries and a poison queue
  • No keys anywhere: managed identity with least-privilege RBAC, user-delegation SAS uploads, secrets in Key Vault, and GitHub Actions signs in to Azure through OIDC
  • Every Azure resource in Terraform (remote state, RBAC, budget alerts), plus an Application Insights workbook and error alerts for monitoring
  • CI/CD with GitHub Actions: tests, analysis and Terraform checks on every push, automatic deploys from main, and each version tag builds a signed Android APK and an iPhone IPA on a macOS runner
  • 540+ automated tests (347 backend, 194 Flutter)
  • Runs for about $0 a month on free tiers, with a daily log cap and budget alerts
The app
  • AI receipt scanning: store, date, time, items and total, with categories that learn from your corrections
  • Dashboards, monthly budgets with 80% / 100% alerts, insights and a month-end forecast
  • Shared household budgets for up to 6 people, joined with an invite code
  • Recurring expenses and bill reminders that keep asking whether a bill was paid until it is
  • Works offline with an upload queue, plus CSV export, a home-screen widget, push notifications and Crashlytics
  • Google sign-in, email verification, English, French and Arabic (right to left), light and dark themes
